# Кошелёк — Telegram Mini App

Личный кошелёк внутри Telegram. Работает бесплатно: одна страница на GitHub Pages,
данные хранятся в облаке Telegram (CloudStorage) у каждого пользователя свои. Сервера нет.

## Что умеет
- «Можно сегодня»: дневной лимит до следующей зарплаты, с учётом аренды и платежа жене.
- 4 конверта: Обязательное, Жизнь, Подушка, Gigly. Каждый приход раскладывается сам.
- Быстрая строка: `40 такси`, `+500 предоплата`, `хочу 300 кроссовки`.
- Частые траты становятся кнопками и запоминают последнюю сумму и способ оплаты.
- Наличные и карта отдельно, сверка кошелька, «снял с карты».
- «Хочу»: цена в днях лимита и пауза 48 часов.
- Анализ: темп, категории, мелочь, выходные против будней, подушка.

## Подключить к боту
```bash
./connect-bot.sh https://<github-user>.github.io/koshelek/
```
