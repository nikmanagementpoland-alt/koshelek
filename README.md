# Кошелёк — Telegram Mini App

Личный кошелёк и финансовый ассистент для жизни на наличных. Бесплатно: статическая страница на GitHub Pages,
данные в облаке Telegram (CloudStorage), у каждого пользователя свои. Сервера нет.

## Что умеет (v3)
- **Всё правится нажатием:** платёж (сумма, «оплатить до», уже оплачено), любая запись в истории (сумма, дата, категория), конверты.
- **Платежи частями:** отдал 200 из 1500 — осталось 1300; план «положи сегодня X» по линии до срока.
- **Жду деньги:** мероприятия, залог, долги. В «можно сегодня» не входят, только в план.

- **Главная:** «можно потратить сегодня», всего денег / на платежи / свободно, большие кнопки ➖ Потратил и ➕ Получил.
- **Ввод:** своя цифровая клавиатура, сетка категорий, быстрая строка `40 такси`, `+500 предоплата`, `хочу 300 кроссовки`.
- **Конверты:** отдельный конверт на каждый платёж (аренда, жене, любые свои) с датой «до какого числа»,
  прогрессом и подсказкой «откладывай по X в день». Подушка и Gigly с лимитом в месяц.
- **После прихода:** подсказка, сколько наличных положить в какой конверт.
- **Ассистент:** календарь на 45 дней с прогнозом дыр, мероприятия (гонорар, предоплата, напоминание забрать деньги),
  анализ трат, сезонность рынка мероприятий, советы для бизнеса, учёт Gigly «вложено / вернулось».
- **Хочу:** цена в днях лимита и пауза 48 часов. **Сверка** наличных раз в неделю.

## Подключить к боту

```bash
./connect-bot.sh https://<github-user>.github.io/koshelek/
```
